# PARALLAX FIGHTER

Parallax Fighter is a "shoot them up"
game developed for the
Super Nintendo Entertainment System
(SNES).

## CONTROLS 

D-Pad:
- Up       : Move spaceship up
- Down     : Move spaceship down
- Left     : Move spaceship left
- Right    : Move spaceship right

Button A, B, X, Y:
- Shoot

Button SELECT:
- Choose from 3 speeds for the spaceship

Button L:
- Stop music

Button R:
- Start music

## COMPILATION
export PVSNESLIB_HOME=/home/user/pvsneslib_440_64b_linux/pvsneslib/  
make
